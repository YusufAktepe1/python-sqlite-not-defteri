# 📝 Dijital Not Defteri (Python + SQLite CLI Uygulaması)

Nesne Yönelimli Programlama (OOP) ilkeleri kullanılarak geliştirilmiş, komut satırı (CLI) üzerinden çalışan güvenli ve modüler bir not defteri uygulamasıdır.

## 🚀 Özellikler
- **OOP Mimarisi:** Modüler yapı (`not_defteri.py`, `veritabani.py`, `main.py`).
- **CRUD İşlemleri:** Not ekleme, listeleme, güncelleme ve silme.
- **Güvenli Sorgular:** SQL Injection açıklarını önlemek için parametreli sorgular (`?` kullanımı).
- **SQLite Entegrasyonu:** Harici bir sunucuya ihtiyaç duymadan yerel veritabanı yönetimi.

## 🛠️ Kullanılan Teknolojiler
- **Python 3**
- **SQLite3**
- **Git & GitHub**
